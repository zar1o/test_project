# Rejestry i VAT — демо-прототип

Редизайн двух экранов польского бухгалтерского сервиса: **«Obszary księgowe»** (хаб) и **«Rejestry i VAT»** (реестр).
Интерфейс опирается на дизайн-грамматику Revolut: пилюли, типографика денег, контрастные CTA. Палитра взята из фона — шёлкового градиента трёх цветов: индиго `#4632dc`, лавандовый `#a096ff`, полночный `#06061c`; карточки из «жидкого стекла» лежат поверх него.

## Визуальный слой

- **Фон** (`components/ui/backdrop.tsx`): WebGL-градиент [gradflow](https://gradflow.meerbahadin.dev) типа `silk`, реагирует на указатель. Пока WebGL не отрисовал первый кадр (или если его нет), под ним лежит статичный CSS-градиент тех же цветов. Слой фона липкий (sticky), а не фиксированный: iOS Safari обрезает фиксированные слои по границе видимой области, и под статус-баром и нижней панелью оставались полосы цвета страницы. На iOS слой заходит под обе панели; выше начала документа и ниже его конца Safari рисует только цвет фона, поэтому там градиент плавно в него переходит.
- **Две темы**: тёмная (по умолчанию, `data-theme="dark"`) — градиент как задан; светлая — тот же шёлк из лавандового и белого. Смена темы плавно перетекает в самом градиенте.
- **Акцент в двух ролях**: `--accent-solid` для заливок (точки, полосы, метки) и `--accent` для текста и иконок, со ступенью под контраст 4.5:1 на стекле каждой темы.
- **Главная** (`pages/hub/`): заголовок в навбаре; по центру приветствие, которое один раз печатается по буквам и заканчивается машущей рукой, под ним поиск по центру; ниже акцентная карточка периода, рейка из четырёх разделов и карточка доступности.
- **3D-объекты на хабе** (`pages/hub/floating-icons/`): иконки разделов и календарь собраны в three.js как объекты из «дисперсного стекла» — насыщенное ядро в толстой прозрачной оболочке, которая его преломляет и раскладывает в спектр по кромке; детали (строки чека, колонны, ручка, кольцо) серебряные. Плюс серебряные кольцо и шарики. Объекты привязаны к элементам страницы с `data-float`, поэтому раскладка задаётся в CSS на любом брейкпоинте; наведение на раздел разворачивает его объект. Саму страницу стекло преломить не может (холст прозрачный), поэтому вне ядра оно рисуется поверхностью: кромка и блики. three.js грузится отдельным ленивым чанком (~132 КБ gzip) после первой отрисовки; без WebGL остаются плоские иконки, при `prefers-reduced-motion` сцена статична.
- **Готовый рендер** (`src/assets/`): стеклянный спаркл у угла рейки разделов. Это картинка в AVIF (~27 КБ), а не объект сцены; покачивается на CSS-анимации.
- **Сводка реестра** (`pages/register/insights.tsx`): акцентная карточка (индиго с лавандовым свечением) с брутто и изменением к прошлому месяцу, график нетто + VAT с переключателем «день / неделя / месяц» (тултип, клавиатура, таблица для скринридера) и серебряная карточка ставок VAT. Цвета серий проверены на различимость при дальтонизме для обеих тем.
- **Стеклянный курсор** (`components/app/glass-cursor.tsx`): точная точка без задержки и линза, которая тянется за ней как капля — вытягивается по ходу движения, раздувается в прозрачный пузырь над всем нажимаемым и сужается в стеклянную черту над полями ввода. Включается только для мыши и пера после первого движения, не включается при `prefers-reduced-motion`; системный курсор прячется лишь пока стеклянный на экране.
- **Открытие приложения**: при первом заходе страница не показывается сразу — в центре по одной складывается колода стеклянных карт и раздаётся по местам (тот же `lib/deck.ts`, функция `introDeck`). Скрытие страницы до первого кадра взводится маленьким скриптом в `index.html`; если приложение не стартовало, через 6 секунд страница возвращается сама. Приветствие на главной начинает печататься только после раздачи.
- **Переход «колода»** (`lib/deck.ts`): при смене страницы все стеклянные поверхности собираются в колоду стеклянных карт в центре экрана и раздаются на новую страницу. Срабатывает на любую смену маршрута, включая кнопку «назад» браузера; данные следующей страницы подгружаются, пока колода собирается (`data/prefetch.ts`). Тайминги — в константе `T` в начале файла. При `prefers-reduced-motion` переход отключён.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build в dist/
npm test           # unit-тесты логики реестра (Vitest)
```

## Стек

| Задача | Выбор | Почему |
|---|---|---|
| Сборка | Vite 7 + React 19 + TypeScript (strict) | SPA без SSR/SEO, мгновенный dev-сервер, статический деплой |
| Стили | Tailwind CSS v4, токены в CSS-переменных | тёмная и светлая темы переключаются одним атрибутом |
| Примитивы | Radix UI (`radix-ui`), cmdk, структура shadcn | доступность, фокус и клавиатура из коробки, свой внешний вид |
| Данные | TanStack Query поверх mock-API с задержкой | настоящие состояния загрузки и ошибки, повтор запроса |
| Таблица | TanStack Table + dnd-kit | сортировка, порядок колонок перетаскиванием (и с клавиатуры) |
| Фон | gradflow (WebGL, ~11 КБ gzip, без зависимостей) | анимированный шёлковый градиент |
| 3D | three.js (ленивый чанк) | стеклянные объекты на хабе; не входит в первую загрузку |
| Анимация | Motion + Web Animations API | морфинг пиллов (`layoutId`), пружины; переход «колода» на WAAPI; учёт `prefers-reduced-motion` |
| Роутинг | React Router 7 | фильтры, период и поиск живут в URL |

Версии зафиксированы на проверенных мажорах (RR7, Table v8, TS 5.9, Vite 7, Motion 12), а не на самых свежих: для демо надёжность важнее.

## Что изменилось в логике

- **Хаб.** В центре стоит поиск документов (⌘K / Ctrl+K) с живыми результатами. Под ним пиллы разделов со статусом. Работает «Rejestry i VAT», остальные помечены как недоступные в демо.
- **Период.** «Rok» и «Miesiąc» объединены в один чип. В календаре точками отмечены месяцы, где есть документы.
- **Второстепенное — за кнопками.** Rodzaj operacji, Kod JPK V7, Serie dokumentów и Etykiety собраны в «Filtry» (на телефоне — нижняя шторка). Печать, сортировка (на телефоне) и сброс колонок вынесены в меню «⋯».
- **Активные фильтры** всегда видны чипами, каждый можно снять одним нажатием.
- **На телефоне** таблица превращается в ленту документов, как в банковском приложении. Полная карточка документа открывается в шторке.

## Состояния

| Состояние | Как увидеть |
|---|---|
| Есть данные | по умолчанию: октябрь 2026 и сентябрь 2026 |
| Пустой месяц | выбрать любой другой месяц. Кнопка ведёт к ближайшему месяцу с документами |
| Ничего не найдено | поиск или фильтры, которые исключают все документы |
| Нет данных совсем | переключатель «Stan» внизу справа → «Pusto», или `?stan=pusto` |
| Ошибка сервера | «Stan» → «Błąd», или `?stan=blad` |
| Загрузка | скелетоны при первом запросе, полоса прогресса при обновлении |

## Структура

```
src/
  components/ui/     примитивы в стиле shadcn (button, chip, popover, dialog/sheet, segmented…) и фон (backdrop)
  components/app/    оболочка, шапка, денежная типографика, empty/error
  data/              типы, фикстуры, mock-API, чистая логика реестра (+ тесты), CSV, prefetch
  lib/               тема, переход «колода» (deck), вход блоков (enter), форматирование
  pages/hub/         «Obszary księgowe» (+ floating-icons: 3D-сцена)
  pages/register/    «Rejestry i VAT»
```

Данные демонстрационные. Итоги октября 2026 по продажам совпадают с оригиналом до гроша: 9700,00 / 2323,00 / 12 023,00 zł.
